# 🚀 C Language Learning Journey

![Language](https://img.shields.io/badge/language-C-blue.svg) ![Status](https://img.shields.io/badge/status-Active%20Learning-green)

Welcome to my C programming repository! This collection documents my entire journey of learning the C language, following the curriculum from the famous **CodeWithHarry** C Tutorial. 

It contains practice sets, solved examples, and mini-projects organized chapter by chapter.

## 📂 Repository Structure

The code is organized sequentially to track progress from basics to advanced concepts:

| Chapter | Topic Covered |
| :--- | :--- |
| **01** | **Basics** (Variables, Keywords, Hello World) |
| **02** | **Instructions & Operations** (Arithmetic, Type Conversion) |
| **03** | **Conditional Instructions** (If-else, Switch Case) |
| **04** | **Loops** (While, Do-While, For loops) |
| **05** | **Functions & Recursion** |
| **06** | **Pointers** (Address, Value at address) |
| **07** | **Arrays** (Multidimensional Arrays, Pointer Arithmetic) |
| **08** | **Strings** (String functions, `<string.h>`) |
| **09** | **Structures** (Structs, Typedef, Arrow operator) |
| **10** | **File I/O** (Reading/Writing text files) |
| **11** | **DMA** (Dynamic Memory Allocation - malloc, calloc, realloc) |

### 🧠 Practice & Application
* **`/Solved Questions`**: Solutions to various algorithmic problems and logic building exercises.
* **`/Learning Projects`**: Mini-projects built to apply the concepts learned in the chapters (e.g., Number Guessing Game).

## 🛠️ How to Run the Code

You can run any file in this repository using a standard C compiler like GCC.

**1. Clone the repository:**
```bash
git clone [https://github.com/NisargChaudhary/C-language-Learning-Journey.git]

**2. Navigate to a specific chapter:**
```bash
cd "Chapter 01 Basics"

**3. Compile and Run:**
```bash
gcc filename.c -o output
./output
